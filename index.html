Como publicar o Projeto SABER no GitHub Pages

Se já escolheste a opção 1, estás no caminho certo: GitHub + GitHub Pages é a forma mais simples, gratuita e robusta de pôr todos os teus ficheiros online com navegação, leitura limpa e um link público fácil de partilhar.

Como criar GitHub Pages

Faz isto uma única vez no teu repositório. Depois, cada atualização é só carregar novos ficheiros e esperar alguns segundos.

  1. Entra no teu repositório no GitHub.
  2. Clica em Settings no menu superior do repositório.
  3. Na coluna da esquerda, entra em Pages.
  4. Em Build and deployment, escolhe Deploy from a branch.
  5. Em Branch, seleciona main e, na pasta, escolhe /root.
  6. Clica em Save.
  7. Espera cerca de 1 a 3 minutos. O GitHub vai mostrar o link do teu site, normalmente no formato https://teu-utilizador.github.io/nome-do-repositorio/.
  8. Garante que o ficheiro principal se chama index.html e está na raiz do repositório.

Estrutura recomendada

Esta organização ajuda-te a manter os blocos separados, facilita a atualização dos ficheiros e deixa o projeto preparado para crescer sem se tornar confuso.

├── README.md

├── 02_SaberSer/
├── 03_SaberSaber/

Atualizar o site

Depois do Pages estar ativo, atualizar é simples. O truque é nunca mexer no processo: só substituir ficheiros, fazer commit e aguardar nova publicação.

  1. Carrega novos ficheiros para o repositório, ou arrasta-os para a interface web do GitHub.
  2. Se mudares um capítulo, mantém o mesmo nome do ficheiro para não quebrares links.
  3. No fim da página, escreve uma mensagem curta como Atualização do Bloco 3.
  4. Clica em Commit changes.
  5. Espera 1 ou 2 minutos e faz refresh ao site público.

Erros comuns

O site não aparece

  1. Verifica se existe um index.html na raiz do repositório.
  2. Confirma se o Pages está configurado para a branch main e pasta /root.
  3. Espera alguns minutos; a primeira publicação pode demorar mais.
  4. Se o repositório for privado, confirma se o teu plano GitHub permite Pages privado ou torna-o público.
