# Projeto SABER

Este repositório contém a estrutura editorial completa do Projeto SABER e um site estático preparado para GitHub Pages.

## Como ativar GitHub Pages

1. Abrir o repositório no GitHub.
2. Entrar em **Settings**.
3. Na barra lateral, clicar em **Pages**.
4. Em **Build and deployment**, escolher **Deploy from a branch**.
5. Selecionar a branch **main**.
6. Selecionar a pasta **/root**.
7. Clicar em **Save**.
8. Esperar 1 a 3 minutos até aparecer o URL público do site.

## Estrutura sugerida

O ficheiro principal do site tem de se chamar **index.html** e ficar na raiz do repositório.
