## Encerramento do Bloco 6

### ENCERRAMENTO (60:00–63:00)

Chegámos ao fim desta jornada pelos cinco Saberes.

Mas este não é um fim.

É um começo.

O modelo dos Cinco Saberes não é uma taxonomia científica universal nem uma escala para medir pessoas.

É uma arquitetura interpretativa.

Uma linguagem.

Um mapa para navegar a complexidade do desenvolvimento humano.

O Saber Ser orienta.

O Saber Estar relaciona.

O Saber Saber compreende.

O Saber Fazer transforma.

O Saber Sentir humaniza e regula.

Juntos, formam um todo maior do que a soma das partes.

Como os dedos de uma mão: separados, têm funções específicas; juntos, criam capacidade para agarrar a vida.

Este foi o sexto bloco do Projeto SABER: a Integração dos Cinco Saberes.

Se ouviste todos os blocos desta série, fizeste uma jornada completa.

Se este foi o teu primeiro contacto, a jornada começa aqui.

Fica com isto:

Não precisas de dominar todos os Saberes perfeitamente.

Precisas de os praticar conscientemente.

Uma escolha de cada vez.

Uma relação de cada vez.

Uma ação de cada vez.

Uma emoção de cada vez.

Obrigado por me ouvires.

Se esta série fez sentido para ti, partilha-a com alguém que precise de ouvir isto.

E lembra-te:

O desenvolvimento humano não é um destino.

É uma jornada.

Não é sobre perfeição.

É sobre presença.

Não é apenas sobre chegar.

É sobre caminhar com consciência.

Com os cinco Saberes como guias.

Este foi o Projeto SABER, comigo, Hugo Maganinho.
